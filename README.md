# JS & TS Basics - Labs

Live demos and examples written in labs (JS & TS Basics course).

Slides: <https://ivapopova-courses.github.io/JS-TS-Basics-Slides/>

The current run of the course works in `main`. When a run ends, it is archived
as a tag and `main` starts fresh for the next run. To get an archived run, open
its tag on GitHub, or clone it with `git clone -b <tag> <repo-url>`.
